# Guided Legal-License Documents Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Upgrade the existing legal-license service so citizens answer guided regulatory questions and the system generates versioned PDF and Word documents instead of asking citizens to edit legal text manually.

**Architecture:** Keep the existing Prisma models, citizen token authorization, private storage, status graph, and admin workflow. Add one central regulatory profile module, JSON answer snapshots, structured review items, a shared normalized document model, PDF and true DOCX renderers, and atomic multi-document archival at submission.

**Tech Stack:** Next.js 16.2 App Router, React 19, Prisma 6/PostgreSQL, Zod 4, Node test runner, Puppeteer Core, Qomra fonts, docx, Tailwind CSS 4.
